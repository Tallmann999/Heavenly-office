# Heavenly Office / Божественная канцелярия

**Heavenly Office** — 2D кабинетный симулятор кармического судьи, где игрок принимает души, изучает их досье, ставит печати, запускает реинкарнацию и наблюдает последствия своих решений.

> **Papers, Please**, но вместо пограничного контроля — небесная канцелярия, кармические досье, спорные души, печати суда и смешные реинкарнации.

---

## О проекте

Ты работаешь в Божественной канцелярии — месте, где души после смерти проходят кармический разбор.
Каждая душа приносит досье: добрые поступки, плохие поступки, странные пометки, ошибки архива, раскаяние, скрытые мотивы и последствия прошлой жизни.

Задача игрока — не просто отправить душу в Рай или Ад, а разобраться в деле:

* кто эта душа;
* что она сделала;
* почему она это сделала;
* есть ли ошибка в документах;
* заслуживает ли дело проверки или апелляции;
* какая реинкарнация будет справедливой.

Главная идея игры — **кармическое расследование + моральный выбор + реинкарнация + коллекция уникальных душ**.

## Короткий pitch

Игрок сидит за столом кармического судьи.
К нему приходит душа. Игрок открывает досье, проверяет поступки, скрытые метки и ошибки архива, ставит одну из печатей, запускает реинкарнационную машину и получает результат.

Иногда правильное решение открывает редкую карту души в коллекции.

---

## Core Loop

```text
Очередь душ
    ↓
Душа приходит к столу
    ↓
Игрок читает досье
    ↓
Проверяет поступки, намерения, пометки и ошибки архива
    ↓
Выбирает печать
    ↓
Запускает реинкарнацию
    ↓
Видит результат
    ↓
Получает очки, монеты, прогресс и карту души
    ↓
Следующая душа
```

## Печати

В игре используются 4 основные печати:

| Печать        | Смысл                                                            |
| ------------- | ---------------------------------------------------------------- |
| **Рай**       | Душа направляется в благоприятный маршрут                        |
| **Ад**        | Душа отправляется в наказательный или низший маршрут             |
| **Проверка**  | Дело уходит в кармический аудит из-за ошибки или неполных данных |
| **Апелляция** | Дело спорное и требует пересмотра                                |

Решение не должно быть примитивным “много добра = Рай, много зла = Ад”.
Важны мотивы, последствия, раскаяние, архивные ошибки и скрытые обстоятельства.

## Реинкарнация

Реинкарнация — одна из главных “сочных” механик проекта.

После выбора печати игрок запускает реинкарнационную машину. Душа улетает через портал и получает новую форму.

Примеры возможных исходов:

* ангельский садовник;
* обычный человек;
* монах-ученик;
* демон-стажёр;
* болотная жаба;
* навозный жук;
* космический слизень;
* светлячок-хранитель.

Реинкарнация должна быть не просто текстом, а визуальной наградой: портал, барабан, новая форма, короткий итог и реакция души.

## Коллекция душ

За идеальное решение игрок может открыть карточку души.

Карточка хранит:

* имя души;
* редкость;
* портрет;
* краткую историю;
* главный грех или добродетель;
* правильную печать;
* идеальную реинкарнацию;
* награду;
* связь с ветками миров.

Редкости:

* Common / обычная;
* Rare / редкая;
* Epic / эпическая;
* Legendary / легендарная.

Уникальные души — один из главных мотиваторов прохождения.
В концепте могут появляться странные персонажи: космические правители, рептилоиды, адские бюрократы, императоры подземных миров, святые тараканы и другие необычные сущности.

## Основные системы

### `HeavenOfficeGameController`

Главный контроллер прототипа.
Отвечает за старт сессии, очередь душ, таймер, выбор печати, начисление очков, ошибки, комбо и завершение смены.

### `SoulDocumentGenerator`

Генерирует досье душ:

* имя;
* возраст;
* краткую биографию;
* добрые поступки;
* плохие поступки;
* специальные пометки;
* лимит времени;
* уровень сложности.

### `HeavenOfficeRulesEvaluator`

Проверяет дело и определяет правильную печать.

Примеры логики:

* архивная ошибка → `Проверка`;
* неполная подпись → `Апелляция`;
* добрых поступков больше → `Рай`;
* плохих поступков больше → `Ад`;
* равный баланс → спорное дело.

### `HeavenOfficeView`

Отвечает за отображение интерфейса, документа, HUD, таймера, выбранной печати, feedback-сообщений и финального экрана.

### `HeavenOfficeConfig`

Конфигурация сессии:

* количество душ;
* лимит времени;
* количество допустимых ошибок;
* базовая награда;
* штраф;
* бонус за скорость;
* множитель комбо;
* настройки сложности;
* runtime UI;
* логирование аналитики.

## Как запустить проект

1. Склонировать репозиторий:

```bash
git clone https://github.com/Tallmann999/Heavenly-office.git
```

2. Открыть проект через **Unity Hub**.

3. Использовать версию Unity:

```text
Unity 6000.2.14f1
```

4. Открыть сцену:

```text
Assets/Scenes/SampleScene.unity
```

5. Нажать **Play**.

## Чем проект отличается от простой сортировки душ

Обычная сортировка душ строится по принципу:

```text
увидел признаки → выбрал Рай или Ад
```

**Heavenly Office** строится иначе:

```text
изучил дело → понял мотив → проверил скрытые пометки → поставил печать → запустил реинкарнацию → увидел последствия → открыл карту
```

Главный фокус — не скорость реакции, а ощущение, что игрок действительно работает кармическим судьёй.
